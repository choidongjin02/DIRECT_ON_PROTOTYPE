    동일 WebSocket 세션

듣는 동안 하는 두 가지 판단

TypeSafe 키가 있으면 기본적으로 두 판단에 모두 Jev를 사용합니다.

발화 종료
end는 무음 650 ms에 종료, hold는 최대 2,500 ms 대기. 유효한 판정이 없으면 무음 800 ms, 이어지는 어미면 1,800 ms 기준을 적용합니다.
업무 분류
중간 전사로 업무 유형과 안내에 쓸 작업을 판단합니다. 키가 없으면 키워드로 분류하고, 업무를 특정하지 못하면 전체 매뉴얼과 도구를 사용합니다.
